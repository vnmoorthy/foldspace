# Contributing to FOLDSPACE

Thanks for flying with us. This is a one-day hackathon project, so keep changes small and focused.

## Build

```bash
brew install xcodegen
scripts/build-sim.sh            # any iPhone simulator, on-screen hinge control
scripts/build-duo.sh            # iPhone Duo simulator, native hinge (Xcode 27.1 beta, DUO_SDK)
DEMO=sun scripts/build-sim.sh   # jump to a demo state: cockpit galaxy outer warp sun weapon blackhole andromeda
```

`Foldspace.xcodeproj` is generated from [`project.yml`](project.yml). Edit `project.yml`, then run `xcodegen generate`. Don't hand-edit the project file. Keys are optional; see [Sponsor stack](README.md#sponsor-stack-supabase--openai--sentry).

## Where things live

| You want to change… | Look in |
|---|---|
| How hinge motion becomes gestures | `Foldspace/Hinge/HingeEngine.swift`, thresholds in `HingeState.swift` |
| What each gesture does | `Foldspace/Game/FlightController.swift` |
| Game rules, costs, save data | `Foldspace/Game/GameStore.swift` |
| Stars, planets, facts | `Foldspace/Universe/UniverseData.swift` |
| The 3D hologram | `Foldspace/Scene/SpaceScene.swift`, `PlanetMaterials.swift` |
| Screens and sequences | `Foldspace/UI/` |
| Rendered textures and movies | `assets/` (generated by `blender/codex/`, see `assets/NOTES.md`) |

The rule that keeps the code simple: **state only changes through `GameStore` methods**. Views observe; `FlightController` and console buttons call methods.

## Adding a star system

1. In `Foldspace/Universe/Universe.swift`, add an id to `SystemID`.
2. In `Foldspace/Universe/UniverseData.swift`, add a `private static let` `StarSystem` next to the others (copy `alphaCentauri` as a template) and append it to `UniverseData.universe`. Keep `sol` first.
   - `distanceLY`: the real distance from Sol.
   - `map`: a `MapPoint` in the unit square for the galaxy map.
   - `primary` and `bodies`: `CelestialBody` values with a `blurb` and 2–3 **true** `facts`. Pick a `planetClass` so the procedural material works without a texture.
   - `act`: 2 for nearby stars, 3 for the galactic core and beyond. Set a `warpCost` in line with its neighbours (30–80 for Act II).
3. Optional: add a Blender texture `assets/textures/planet-<bodyid>.png` (2048 × 1024 equirectangular). Without one, the runtime material is used.
4. Cite a source for new numbers (NASA Exoplanet Archive preferred) in the PR description. Mark non-transiting radii as estimates.

## Pull requests

- One topic per PR, with a short description and, for UI changes, a simulator screenshot (the `FOLDSPACE_DEMO` hook makes this easy).
- It must build: `scripts/build-sim.sh`, or wait for the [CI workflow](.github/workflows/build.yml) to go green.
- Keep the game playable offline and on a flat iPhone: every hinge verb needs a console-button path.
- Nothing may block touches across the fold except the probe drag.
- No Star Wars (or other franchise) names. Real astronomy, original names.
- Never commit `Foldspace/Secrets.plist` or any keys.
